# 背单词（vocab-pwa）

自己的词表，**看英文写中文 / 看中文写英文**，两个方向都是手打（不是选择题）；
词可以同时归入多个分级词库；按遗忘曲线自动排复习。iPhone 和 Windows 都能装，**离线能用**。

纯 HTML + CSS + 原生 JS，零依赖、零 CDN；数据存在你自己浏览器的 IndexedDB 里，不上传任何服务器。

---

## 这是什么

一个**背单词 PWA**：导入自己的词表（Excel / CSV / 直接粘贴），两个方向手打练习，
按 Leitner 遗忘曲线自动排复习，生疏词/熟记词自动成组。**数据只存在你自己的设备上**，
不上传任何服务器，断网也能用。

**打开就能用 → https://qqwer13526-gif.github.io/vocab/**

| 想怎么用 | 怎么做 |
|---|---|
| 电脑上试一下 | 打开上面那个网址 |
| **安卓**装成 App | Chrome 打开 → 右上 `⋮` → 「安装应用」（图标进桌面、独立窗口、离线可用） |

| 自己托管一份 | 在 [Releases](../../releases) 里下载 `vocab-*.zip`，解压到任意静态服务器即可（零依赖、无构建） |

用 Edge 打开 <http://127.0.0.1:5173> → 地址栏右侧的**安装**图标（或 `…` 菜单 → 应用 → 安装此站点）

## ⚠️ 手机上必须知道的两件事（不然会丢数据）

iOS 有几条关于网页应用的规定，不了解就会踩坑：

1. **主屏幕上的应用和 Safari 里打开的网页是两套独立存储**
   （WebKit 的既定行为，见 [bug 181849](https://bugs.webkit.org/show_bug.cgi?id=181849)）。
   也就是：在 Safari 里打开同一个网址，看到的**可能是空的**，而你的数据好好待在**主屏幕那个应用**里。
   → **平时就用主屏幕图标打开**。
2. **删掉主屏幕图标 = 连它的数据一起删掉**；重新"添加到主屏幕"会得到一个**全新的空应用**。
   → **千万不要用"删了重加"来更新**。

### 怎么更新：应用里的「立即更新」

应用打开时、切回前台时、网络恢复时都会**主动检查新版本**，三层保险：

1. 取一次 `version.json`（`no-store`，绕开缓存）跟自己的版本号对比 —— **不依赖 service worker 的任何行为**
2. 顺手让浏览器去取新的 `sw.js`（注册时用了 `updateViaCache: 'none'`，检查更新时不走 HTTP 缓存）
3. 发现新版就在顶部显示蓝色横幅「有新版本 v9，更新后数据不会丢 · **立即更新**」

点「立即更新」时除了让新 SW 接管，还会**清掉所有缓存**再重载 ——
这是对付"旧 service worker 卡在旧代码上"最有效的一招（**数据在 IndexedDB 里，不受影响**）。
也可以在首页底部 →「设置」→「检查更新」手动查。

> **为什么有时候要等一会儿**：GitHub Pages 给所有静态文件设了 `Cache-Control: max-age=600`，
> 所以**发版后最多 10 分钟内**，手机上的浏览器可能还在用 HTTP 缓存里的旧 `sw.js`。
> v9 起应用自己用 `no-store` 取 `version.json`，基本能立刻发现；真碰上不生效，就点「立即更新」。

### 保险：导出备份

「设置」页 →「导出备份文件」会生成一个 JSON（不含 3.8MB 音标库），iOS 上会弹出"存储到文件"，
存到「文件」App、iCloud 或发给自己都行。**换手机、误删图标、哪天数据不见了**，都用「从备份恢复…」救：

- **合并进来**：备份里较新的那份并进来（换手机、两边都有数据时用）
- **覆盖本机**：清掉本机现有数据再导入（本机数据乱了时用）

「设置」页还能看到**本机数据概况**（词条 / 词库 / 学习记录 / 占用空间）和**持久化存储**状态，
建议点一下「申请持久化存储」，这样系统空间紧张时不会优先清理你的数据。

## 界面怎么走

- **底部胶囊三格**：词库（首页）/ 导入 / 设置。练习时胶囊自动收起，键盘弹出时也收起
- **首页只有词库**（v18 起）：
  - 顶上钉着**总词库** —— 所有导入过的词都在里面，**删词库也删不掉它**
  - 再下面是你自己的词库。**整行都能点**（不用精准点中名字），点进去就是这个词库页
  - 每行右边的 `⋯`：**练整库 / 重命名 / 删除词库**；列表末尾一行「＋ 新建词库」
- **词库页**里有：
  - **生疏词 / 熟记词**两块：点那一行就**直接专项练这一档**（想看这批词就用下面的筛选条）。
    总词库页里的这两块是**全局**的（所有库一起算）
  - **练整库**按钮（练这个词库到期的 + 新词）
  - 词条列表：**点单词本身 = 改这个词；点行的空白处 = 从这个词开始背**（右边的「练」是同一个动作，
    给键盘和读屏用）。列表里只显示 **生疏 / 熟记 / 未标**，不再显示"盒 3"这种内部编号
- **删词库只删库，不删词**：库没了，词还留在总词库里（共享给别的库的词不动）。删完右下角会弹一条
  提示，6 秒内点「撤销」可以整个恢复
- 行里只给数字，不写说明句（v21 起）：「生疏词 24 个词」就是全部信息
- **补音标**在 **设置 → 本机数据**（以前在首页底部）
- **练习页的「选词」**：顶部右侧点开，能看到这一轮的全部词、每词的本轮结果，点哪一行就跳到哪一题
  （跳过去那题可以重答；跳题会清掉「上一题」的回退历史）

## 导入自己的词表

1. 在 Excel 里**选中「单词」和「释义」两列**（整列选，不要选标题行也行）
2. `Ctrl+C` 复制
3. 打开应用 → 底部「导入」→ 粘进大框里
4. 它会自动认出哪列是单词、哪列是释义（**认错了可以手动改**），下面给出前 5 行预览
5. 勾上要放进哪个词库（可以多选，也可以现场新建）→ 点「导入」

也可以点「选择文件…」直接选文件，**`.xlsx` 也能直接选**（应用会自己解压读出来，不需要任何库或转换），
另外还支持 `.csv` / `.tsv` / `.txt`（Excel 另存的 CSV 也认，UTF-8 和 GBK 都能读）。
老式的 `.xls` / `.ods` 读不了，请在 Excel/WPS 里「另存为 .xlsx」。

**它会自动处理**：
- 标题行、`总词数 187` 这种统计行、空行 → 跳过
- 表头不在第一行（你的《英语词汇背诵检查表》表头在第 4 行）→ 照样认得出
- 释义是英汉混排（`take in or soak up吸收；使专心`）→ 存两条，写「吸收」就算对
- 「常用搭配」列 → 存进例句字段
- 已经有的词：默认跳过，也可以选「合并释义」把新释义并进去
- 整个导入是**一个事务**：中间出错就一条都不写，不会留下半截数据

想先看看界面长什么样：打开 <http://127.0.0.1:5173/tool/seed_demo.html> 点「灌入示例数据」，
回到首页就有了 2 个词库 + 12 个词（含到期的复习词）。「清空全部数据」可以随时归零。

### 更省事的办法（可选）：批量把 Excel 转成 `.tsv`

应用本身已经能直接读 `.xlsx` 了，所以这一步不是必须的。但如果你想把很多份表一次转好、
或者想在电脑上先看一眼认出了多少词，可以用这个脚本：


转换结果放在原文件旁边（同名 `.tsv`），并且会自动用应用那套解析逻辑跑一遍自检，
告诉你认出了多少词、哪列是哪列。

你的《英语词汇背诵检查表（一）》已经转好了一份：
`D:\Study\CET\英语词汇背诵检查表（一）.tsv`（187 个词）。

## 手机上拖不动？先打开调试浮层

「过一遍」模式的卡片是可以用手指左右拖的。要是拖不动，**别猜，开浮层看**：

1. 设置 → 调试 → 打开「练习页显示滑动调试浮层」（存在 localStorage，不用手输网址）
2. 回到练习页（过一遍模式），在卡片上拖一下
3. 左上角会实时显示：

```
滑动调试
模式：过一遍（可拖）            ← 写着"默写"的话，滑动本来就是关的（点右上角换模式）
touch-action：none             ← 应该是 none；是 pan-y 的话 iOS 会把带纵向的拖拽判给滚动
click 阈值：可拖
down 3 · move 27 · up 2 · cancel 0
拖动中：是 · dx 42px
```

怎么读：

| 现象 | 说明 |
|---|---|
| `down` 一直是 0 | 触摸压根没到卡片（有东西挡着，或者卡片不是那个元素） |
| `down` 有、`move` 没有、`cancel` 涨 | 浏览器把手势判给了滚动 —— 就是 `touch-action` 的问题 |
| `move` 在涨但 `dx` 不动 | 事件到了，是位移没写上去（逻辑问题） |
| 模式写着"默写" | 正常现象：默写模式不接管横向手势 |

> 这条对 PWA 特别有用：无头浏览器里合成的事件跑得通，**不代表真机跑得通** ——
> `touch-action`、`pointercancel` 这类只有手机上才暴露。

## 复习规则（Leitner 六盒）
| 盒子 | 答对后 | 该盒子的间隔 |
|---|---|---|
| 1 | → 2 | 10 分钟 |
| 2 | → 3 | 1 天 |
| 3 | → 4 | 3 天 |
| 4 | → 5 | 7 天 |
| 5 | → 6 | 21 天 |
| 6（已掌握） | → 6 | 60 天 |

- 下次复习时间 = 现在 + **判完之后所在盒子**的间隔（新词第一次答对 → 1 天后见）
- **答错** → 回盒子 1，10 分钟后再来
- **差点**（拼错一个字母）**不升不降**：
  - 中→英：提示「再试一次」，**不算错、不写库**，重打对了才算过
  - 英→中：给「算我对」按钮，由你自己定夺
- 每日队列 = 到期的复习词（按到期时间）+ 新词（默认每天 10 个）

### 抽查时自己定级：熟记 / 生疏

练习界面每道题下面常驻两个按钮（点了自动进下一题）：

| 点哪个 | 复习计划 | 标记 |
|---|---|---|
| **熟记** | 直接进盒子 6 → **60 天后再见** | 记成"熟记" |
| **生疏** | 回盒子 1 → **10 分钟后再见** | 记成"生疏" |

- 就算这题已经答过（盒子按对错变过），**手动一点就覆盖**
- 两个按钮**不会**增加"答错次数"（那是答题统计，不混一起）
- 在词条界面可以按它筛选：`全部 / 熟记 / 生疏 / 未标`（带数量）

**答错会自动进生疏库**（不用手点）：

| 发生什么 | 结果 |
|---|---|
| **答错** | 自动标生疏 → 进生疏词库（答错时的反馈条里会写一句） |
| 答对 | 标记**不动**（生疏的词答对一次还留在库里） |
| 一路答对**爬到"已掌握"（盒 6）** | 自动**移出**生疏库，改记熟记 —— 不然这个库只增不减 |
| 手动点「熟记 / 生疏」 | 覆盖以上一切 |

**答完想回去改？** 练习页左上角「**↶**」= 回退到上一个词，并**撤销那一次的作答**
（进度原样还原；第一次学的新词会彻底删掉，明天还算新词）。回去可以重新答，按新结果重新计分。

### 生疏词会自动变成一个库（进去一遍过完）

首页最上面有个**「生疏词」库**（虚线框、带「自动」标记）：

- 练习时点一次「生疏」，那个词就**自动进来**；标成「熟记」就**自动移出** —— 永远和你的标记一致
- 点它的**名字** → 直接进去学：用的是「**过一遍**」模式，**一次一个词，词 + 音标 + 释义全都摊开给你看**，
  你只管点「熟记」或「生疏」，一遍把整库过完（**不默写** —— 生疏的词本来也打不出来）
  - 「下一个（不标）」可以只过不改
  - 过完给成绩单：`过了一遍 N 个词 · 熟记 a · 生疏 b · 跳过 c`
  - 想考自己的话，右上角「**换成默写（考自己）**」切回默写模式
- 进去时**不看到期时间**：这个库里的词你想现在啃就现在啃，不受每天新词上限限制
- 点右边的**箭头** → 看这批词条
- 「熟记词」也会在它有内容时出现（相当于"已掌握清单"）

> 它是"实时算"的，不是复制一份词表 —— 所以你在词条页改标记、或者恢复备份之后，它都不会和真实状态不一致。

### 配色与对比度（浅色 / 深色 / 系统要求高对比）

| 处境 | 表现 |
|---|---|
| 普通（浅色或深色） | 正文、次要文字、强调色、对/错提示全部 **≥ 4.5:1**（WCAG AA） |
| 系统开了「提高对比度」 | 次要文字提到正文级、描边加深、半透明浅底换成实底+描边，正文拉到 **≥ 7:1**（AAA）；只改颜色，不动尺寸/间距/动效 |
| 焦点圈 | 只在键盘操作时出现（`:focus-visible`），2px 实线；高对比模式下 3px |

颜色令牌是全局的：改一个 `--ok` 会同时影响「熟记」按钮、判定反馈条、档位标签、提示条好几处，
所以有 `tool/check_contrast.py` 把关 —— 它把 `style.css` 里真实用到的**前景/背景组合**
（含 `color-mix(... N%, transparent)` 这种半透明底，会先跟 `--bg`/`--card` 合成再算）
全部算成对比度，低于门槛就红。四种处境（浅色 / 深色 / 高对比浅色 / 高对比深色）一起查。

> 小坑：浅色模式下 `--ok` 这种深绿，压在自己 14~18% 的浅绿底上，对比度反而掉到 3.9~4.5。
> 所以有 `--ok-ink` / `--warn-ink` / `--bad-ink` 三个"墨色"，专门给有浅底的文字用。

### 层次：深色模式不靠描边

浅色下卡片靠"更白 + 淡阴影"，深色下阴影基本看不见 —— 所以深色里把卡片面提亮一档
（`--card: #1c2024`）并加一条 1px 内高光（`--shadow-1` 里那个 `inset`），边界不用描边也看得清。

### 图标与宽屏

- 箭头 / 关闭 / 回退 / ⋯ / 垃圾桶这类图标是**内联 SVG**（`src/icons.js`），不是字体里的 `‹ › ✕` ——
  那些字形在不同系统里粗细、基线、大小都不一样，字号一变就跟着乱；SVG 能锁死比例与线宽。
  装饰性图标一律 `aria-hidden`，按钮的可访问名字仍靠 `aria-label`
- 底部导航是**悬浮胶囊**（内缩 + 毛玻璃 + 药丸选中态），内容从它下面滚过去；宽屏收成 420px 居中
  - 尺寸和动效是照着一段参考录屏**逐帧量出来**再定的：宽占屏 **70%**、高 **60px**、贴着屏幕下沿；
    切换时是一颗白药丸**滑**到目标格（170ms，带 2~3% 过冲），图标与文字颜色交叉淡入，内容不跟着位移
  - 配色是 iOS 惯例的**灰底 + 白卡**（这样半透明的胶囊才"比页面亮"，看得出是块玻璃）
  - 系统开了「减弱动效」时，药丸不再滑动、只换颜色
- **宽屏（≥900px）**：容器放宽到 960px，首页排成两栏（左边固定入口、右边词库列表），
  不再是一条居中的细长带；手机上仍然是单列

| `/` | 词条列表 | 跳到搜索框 |
| `Esc` | 词条列表搜索框 | 清空搜索与筛选 |

**故意不加**：全局搜索、快捷键面板之类 —— 这是个人学习工具，不是编辑器。

### 空状态都给出"下一步"

没有词库 → 直接给「去导入词表」；搜不到词 → 给「清空搜索与筛选」（顺手把 URL 上的筛选参数也还原）；
今天没得练 / 生疏库是空的 → 给「回首页」和一个解释。

### 动效（克制的那几处）


动效只加在"有理由"的地方，规矩来自 Emil Kowalski 的动画标准（用 `review-animations` 这个 skill 审过）：

| 地方 | 动效 | 时长 |
|---|---|---|
| 判定反馈条（对/错） | 从下方 6px 浮起 + 淡入 | 170ms |
| 换下一题 | 词/释义轻微上浮淡入（WAAPI，只动 transform/opacity） | 170ms |
| 「过一遍」里左右滑动卡片 | **1:1 跟手** → 松手按**惯性投射**的落点决定翻页或回弹，手指末速交给弹簧；飞行中能再抓住；拖过一张卡宽后上橡皮筋 | 拖拽实时 / 弹簧 ~300ms（解析解，各帧率一致） |
| 按钮按下 | 缩到 0.97 | 110ms |
| 进度条（掌握率） | `scaleX` 而不是 `width`（宽度会触发布局、掉帧） | 240ms |
| 顶部「有新版本」横幅 | 从上方滑入 | 240ms |

**故意不加**：打字、切标签、列表滚动（高频操作加动效是负分）。
**减弱动效**：位移和缩放归零，只保留很淡的透明度变化（不是全关）。

### 字体：词头用字典式衬线

英文词头（练习页那个大字、词条编辑页的标题）用 **Instrument Serif**（衬线体），中文界面/按钮/释义一律系统无衬线 ——
像纸质词典那样，只让"词"有存在感。

- 字体是**本地打包**的（`fonts/InstrumentSerif-Regular.ttf`，67.7KB，SIL OFL 1.1，许可证见 `fonts/OFL.txt`），
  **不联网、不走 CDN**，已进 service worker 预缓存 → 离线也有
- 中→英方向（提示是中文释义）**不用**衬线体：中文衬线在不同系统上差异太大
- 想换风格的话，`ui-styling` 那个 skill 里还打包了 28 个开源字体（OFL），说一声就换

### 音标：一键补齐

词条界面顶部（以及首页底部，只在真缺音标时出现）有「补齐音标（还差 N 个）」：

1. 第一次点会下载音标库：**英式 1.3MB**（四级/高考的习惯口音）+ 英式查不到时用**美式 2.5MB 兜底**
   （英式库不全，实测你那份 187 词的表英式只覆盖 169 个，加上兜底就是 **187/187**）
2. 然后自动给所有缺音标的词补上，练习和词条里就能看到音标了
3. **之后完全离线**：再补新词不用重新下载；两级都查不到的词会被记住，按钮不会一直挂着

> 如果 jsDelivr 在你那儿打不开，可以在浏览器控制台把地址指到别的镜像：
> `localStorage.vocab.dictUrl = '英式镜像地址'`、`localStorage.vocab.dictUrlFallback = '美式镜像地址'`

判定细节：忽略大小写、空格、全角半角、标点；英文侧只忽略首尾空格，内部空格算数（`ice cream` ≠ `icecream`）；
撇号算数（`can't` ≠ `cant`）。

## 发布到 GitHub Pages

在这个目录里执行（把 `你的用户名` 换成你的 GitHub 用户名）：

```powershell
git remote add origin https://github.com/你的用户名/vocab.git
git branch -M main
git push -u origin main
```

然后在 GitHub 网页上：仓库 **Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / `root` → Save**。
等 1 分钟，地址就是 `https://你的用户名.github.io/vocab/`。

> 免费账号的 Pages 需要仓库是 **public**。词表数据存在浏览器里，**不会**跟着代码上传。
>
> 如果 `git push` 报 `Connection was reset`（这台机器直连 GitHub 偶尔会这样），走本地代理再来一次：
> ```powershell
> git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897 push origin main
> ```
