## 目标

做一个自己用的背单词 PWA：粘贴 Excel 词表导入 → 词归入一个或多个分级词库 → 两个方向手打练习 → 按 Leitner 六盒自动排复习 → iPhone 加到主屏幕、Windows 装成应用，离线可用。第二阶段接 Supabase 同步。

## 技术栈

- **纯 HTML + CSS + 原生 ES 模块**。零运行时依赖、**零 CDN**（大陆网络也能用，且离线）
- IndexedDB 存数据；PWA（manifest + service worker）
- 纯逻辑（`srs.js` / `judge.js` / `parse.js`）不碰 DOM → 用 Node 内置测试器 `node --test` 跑
- DOM/存储层 → 浏览器内测试页 + 无头 Edge 断言
- 验证脚本一律用 **Python** 写（PowerShell 拼引号会坏）
- 开发期需要本地 HTTP 服务（service worker 在 `file://` 下不工作）

```js
export const MIN = 60 * 1000, DAY = 24 * 60 * MIN, MAX_BOX = 6;
export const INTERVALS = [0, 10 * MIN, 1 * DAY, 3 * DAY, 7 * DAY, 21 * DAY, 60 * DAY];

export function newProg(wordId, now) {
  return { wordId, box: 1, dueAt: now, streak: 0, lapses: 0, lastDir: null, updatedAt: now };
}
export const isNew = prog => !prog;

export function grade(prog, correct, { now, dir = null }) {
  const p = { ...prog, lastDir: dir ?? prog.lastDir, updatedAt: now };
  if (correct) { p.box = Math.min(MAX_BOX, prog.box + 1); p.streak = prog.streak + 1; }
  else { p.box = 1; p.streak = 0; p.lapses = prog.lapses + 1; }
  p.dueAt = now + INTERVALS[p.box];
  return p;
}

export function buildQueue({ words, progs, links, libIds, now, newLimit = 10 }) {
  const inLib = libIds && libIds.length
    ? new Set(links.filter(l => !l.deleted && libIds.includes(l.libId)).map(l => l.wordId))
    : null;
  const alive = words.filter(w => !w.deleted && (!inLib || inLib.has(w.id)));
  const review = [], fresh = [];
  for (const w of alive) {
    const p = progs[w.id];
    if (!p) fresh.push(w);
    else if (p.dueAt <= now) review.push({ id: w.id, dueAt: p.dueAt });
  }
  review.sort((a, b) => a.dueAt - b.dueAt);
  fresh.sort((a, b) => (a.createdAt ?? 0) - (b.createdAt ?? 0));
  return { review: review.map(r => r.id), fresh: fresh.slice(0, newLimit).map(w => w.id) };
}
```
