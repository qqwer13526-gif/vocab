## 一、顶部虚化：先定性 —— **不是我们画的**

我把 `style.css` 翻了一遍：

| `backdrop-filter` 出现次数 | **只有 1 处**：底部悬浮胶囊（`#tabbar`）。顶部没有任何毛玻璃 |

**我这边能做的三件事**（都是小改动，做完给你前后截图）：

|---|---|---|---|
| 1 | `apple-mobile-web-app-status-bar-style` → `black`（完全不透明） | 状态栏区域不再透出内容 | 无 |

**推荐先做 1 + 3**（无副作用），你再截图对比；还糊就加 2。

## 二、每个词库内置「生疏词 / 熟记词」专项（核心）

现状：生疏/熟记是**全局**智能库，只挂在首页那张「自动收集」卡上。

改成：**进入任何词库，里面都有这两个内置入口** —— 练的是"这个词库里的"生疏/熟记词。

**词库页**（复用已有的词条页 `#/word?lib=X`，现在的样子：返回 + 库名 + 搜索/筛选/词条列表）：

```
‹  四级 Test 1
┌ 内置 ────────────────────────────┐
│ ● 生疏词   24 个词   [▶ 专项练]  ›│   ← 点 ▶ 直接开练；点行 → 看这批词
│ ● 熟记词   33 个词   [▶ 专项练]  ›│
└──────────────────────────────────┘
[ 练整库（187 词） ]                  ← 整库练习的入口（原来挂在首页库名上）
[ 搜单词 / 中文释义 ]  187 个词
[全部][熟记 33][生疏 24][未标 130]     ← 现有筛选
词条列表（每行右侧多一个 ▶「从这个词开始背」）
```

**总词库**同理（`#/word` 不带 lib）：顶部两块 = 全局生疏词 / 全局熟记词，下面是全部词条列表。
**首页那张「自动收集」卡删掉**（这是你要的"不在主页显示"）。

### 路由与队列（都复用现成通道，不动数据模型）

| 入口 | 路由 | 队列怎么来 |
|---|---|---|
| 本库生疏词 | `#/practice?lib=X&level=unfamiliar` | 取 `libWordIds(X)` 里 `prog.level === 'unfamiliar'` 的 —— 走现成的 `buildQueue({ wordIds })`，和智能库同一条路 |
| 本库熟记词 | `#/practice?lib=X&level=known` | 同上，`level === 'known'` |
| 从任意词起背 | `#/practice?lib=X&from=<wordId>` | 正常建队列后**从这个词开始**：该词强制排第一位（不在到期队列里也拉进来），其余按原顺序接在后面 |
| 整库 | `#/practice?lib=X` | 不变 |

生疏/熟记**不存数据**（还是按 `prog.level` 实时算）—— 存一份就一定会和标记不同步（词条页改标记、恢复备份都会对不上），这条规矩继续守。

## 三、点词库 = 整行可点（不用点中名字）

现状：只有库名那个按钮能点（= 直接开练），行的其它地方没反应。

改成：
- **整行（含统计行、进度条区域）都可点 → 进这个词库页**（因为现在库页里才有"生疏/熟记/任意词起背"这些入口）
- 右侧 `⋯` 仍然只开菜单（点它不会顺带进库）
- 无障碍：库名按钮保留（键盘 Tab / 读屏用），整行点击是"给鼠标和拇指的便利层"，不改语义
- 点击热区 ≥44px（现在整行 72px，天然满足）

> ⚠️ 需要你确认的一点：这样改之后，**"点库名直接开练"就没有了**（改成进库页，练整库变成库页里的一个按钮，一次点击之差）。
> 如果你更想保留"点名字 = 直接开练"，我就做成：**点行的空白/统计区 = 进库页，点名字 = 直接开练**（两者都留着）。
