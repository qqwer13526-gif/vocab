> 状态：**已实施并通过验收**（2026-09-26）。用户的原始要求：
> ① 帮我把中文释义和英文释义分开；
> ② 把左上角的"← 左滑算生疏 · 右滑算熟记 →"删去；
> ③ 把右上角的"选词"和"换成默写…"做成选项框。

---

## 1. 中文释义 / 英文原释义分栏

真实词表里的释义是**英汉混排**的一条字符串（`"take in or soak up吸收"`、`"poetry诗节"`、`"韵文"`）。
判题模块 `judge.js` 早就有一个切分函数 `scriptParts()`（在字母↔汉字的交界处切开，判题用它生成"可以命中的答案"）。

所以这次**不新写切分**，而是给它加一个显示用的包装：

```js
glossParts('take in or soak up吸收') // → { zh: '吸收',            en: 'take in or soak up' }
glossParts('poetry诗节')             // → { zh: '诗节',            en: 'poetry' }
glossParts('韵文')                   // → { zh: '韵文',            en: '' }
```

- 好处：**显示出来的中文，就是判题接受的中文**（同一刀切出来的，不会出现"照着屏幕上打却判错"）
- 顺手处理切分留下的落单括号：`测试）` → `测试`、`test（` → `test`，而 `存取（信息）` 的成对括号保留
- 渲染：一条释义 = 中文一行（主）+ 英文原释义一行（次、`--muted` 13px）；只有一边就只画那一行
- **中→英的题目也这么排**（原来是把 `meanings` 用 `；` 拼成一整行混排），字号压下来，中文仍是主角

## 2. 删掉「← 左滑算生疏 · 右滑算熟记 →」

- `.swipe-tip` 元素与样式一起删（两个模式都不再出现）
- 卡片手势**不动**：拖动时照样浮出红/绿角标；翻词有滑片，规则的细节（几天后再见）写在 SPEC §4.1 和 README 表格里

## 3. 「选词」和「过一遍 / 默写」都做成选项框

```
✕  ↶  第 2/29                         [ 选词 ]      ← chip（原来是一行蓝色文字链接）
[ 过一遍 | 默写 ]        [ 英→中 | 中→英 | 混合 ]     ← 两个 .seg-box 并排一行
```

- `过一遍 / 默写`：两格选项框，`aria-pressed` 标当前模式（原来是「→ 换成默写（考自己）」这种文字链接，
  它还得靠文案说"点我会变成什么"，其实不如一个选中态清楚）
- `选词`：小 chip（描边 + 卡片底 + 强调色文字），展开时底色变强调色浅底
- 两个框与"方向切换"共用 `.seg-box` 外观；`dirSwitch` 从顶栏挪到第二行，与模式框 `space-between` 并排；
  过一遍模式下方向框收起，模式框独占一行；太窄（<360）会整块换行，不会把文字挤断
