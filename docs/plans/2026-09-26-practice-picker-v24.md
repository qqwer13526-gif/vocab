## 二、练习页加「选词列表」

**要解决的问题**：`第 1/29` 只能一题一题往下走；想直接跳到"第 17 个词"、或者看看这一轮还剩哪些没练，现在没法看。

**入口**（放在顶部那一行的右侧）：`选词`（或 `这一轮 29 个词`）

**展开形态（推荐：内联折叠）**——点一下在卡片下方展开一块可滚动的列表，再点收起。理由：和现有 `⋯` 行内菜单同一套模式，不引入遮罩/抽屉这类新组件，手机上也不会挡住卡片。

```
✕  ↶  第 3/29        英译中 中译英 混合
[ 选词 ▾ ]
┌──────────────────────────────┐
│  1  cable              ✓ 熟记 │
│  2  distribute         生疏   │
│  3  acceptance        ← 当前  │
│  …（可滚动，最多 40vh）        │
└──────────────────────────────┘
[ 卡片：第 3 题 ]
```

- 每行显示：序号 + 词（英→中方向显示单词；中→英方向也显示单词，因为找词更直观）+ **本轮结果**（✓ 熟记 / 生疏 / 未练）
- **当前题高亮**，点了就跳过去；跳过去之后这道题重新作答（已答过的也会被重置成"待答"，可以重答）
- 为了显示"本轮结果"，会话里加一张 `s.done = { 词id → 'known' | 'unfamiliar' | 'ok' | 'bad' }`（只活在内存里，不影响数据）
- 跳题会清空「上一题」的回退历史（避免撤销撤到别的题上）—— 这条我会写进 SPEC，免得当成 bug

**不做**：不做拖拽排序、不做"只练选中的几个词"（那是另一个功能，你要的话下一版单独说）。
