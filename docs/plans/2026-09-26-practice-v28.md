# v28 方案：整个选词列表吸顶（「选词模式」）

> 状态：**已实施并通过验收**（2026-09-26）。用户提议："将整个选词列表吸顶怎么样" —— 采纳。
> 在 v27（顶栏吸顶 + 跳题自动收起）的基础上，把**列表本身**也钉住。

---

## 1. 为什么只吸顶栏还不够

v27 的顶栏吸顶解决了"收起按钮被滚出屏幕"，但列表本身仍然会随页面滚动被切掉一截：
列表自己有 `max-height` + `overflow: auto`，手指落在列表上滚的是**列表**，页面不动 ——
想看清列表的另一头就得先把页面滚到合适位置，而页面一滚，列表顶部又钻到吸顶栏底下去了。

## 2. 做成「选词模式」

展开期间（视图挂 `.picker-open`）：

| 层 | 表现 |
|---|---|
| 顶栏 | `position: sticky; top: var(--safe-t)`（v27 就有），永远是"收起 / 进度 / ✕ ↺" |
| 列表 | `position: fixed`，钉在顶栏正下方：`left: var(--prac-left)`、`width: var(--prac-w)`、`top: calc(var(--safe-t) + var(--prac-top-h))`、`max-height` 吃到 `100dvh` |
| 页面 | **锁住不滚**（`body.style.overflow = 'hidden'`），列表自己在里面滚 + `overscroll-behavior: contain` |

- **几何全部实测**：`measurePickerBox()` 量顶栏高度与卡片的位置/宽度塞进 CSS 变量（顶栏在 390px 会换行、
  卡片在桌面是居中的，写死一定贴歪）；`ResizeObserver` 盯着顶栏与卡片，转屏 / 键盘收起 / 缩放后自动重算
- **高度用 `dvh`**：iOS 地址栏伸缩时 `vh` 会把列表顶出屏幕，`dvh` 才准（`vh` 那条留着当兜底）
- 跳题后自动收起（v27），并 `scrollTo({ top: 0 })` 把选中的那一题带回眼前（减弱动效时直接跳）

## 3. 取舍（写清楚）

- 列表展开时会把卡片盖住 —— 这是有意的：你此刻是在挑词，不是在看词；"当前"那一行的高亮仍在给你上下文
- 退出方式有两条：右上角「收起」，或者挑一行（挑完自己收起）
