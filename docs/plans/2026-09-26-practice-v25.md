# v25 方案：卡片只留两颗药丸 + 下方翻词滑片 + 默写答完揭晓释义与搭配

> 状态：**已实施并通过验收**（2026-09-26）。用户的原始要求：
> ① 删掉大卡片里的「下一个（不标）」，只留生疏 / 熟记，并与下方的药丸对称；
> ② 卡片下方加一个滑片，左滑回上一个单词、右滑到下一个单词；
> ③ 默写模式下答完之后，把**所有释义和搭配**展出；
> ④ 顺手删掉卡片里"看清了就点……"那行说明。

---

## 0. 一个关键发现：搭配字段早就有

数据模型里本来就有 `example` 字段（`db.js` 的 `example: c.example || ''`）：

- 导入认表头：`常用搭配 / 搭配 / 例句 / 用法 / 短语 / example / collocation / phrase`
- 词条编辑页有输入框，占位符写的就是"例句 / 常用搭配"

**只是练习卡从来没显示过它。** 所以第 ③ 条不动数据库、不做迁移、不加迁移版本 —— 纯显示层的活。

## 1. 卡片：删「下一个（不标）」+ 删底部说明行

- `btn-skip` 连 DOM、CSS、逻辑一起删；`skipOne()` 保留，改由滑片右滑 / 键盘 → 调用
- `.level-hint`（"看清了就点：熟记 → 60 天后再见……" / "自己定：……"）整块删掉，两个模式都不再显示
- 卡片里只剩 `生疏 | 熟记`：`flex: 1` 各占一半 + 12px 间距 → **关于中轴对称**；
  与下方滑片**同宽同轴**（都是卡片宽度），上面两颗药丸、下面一条轨道里一颗药丸
- 空间语义上下一致：左边永远是"左"（生疏 ↔ 上一个），右边永远是"右"（熟记 ↔ 下一个）
- 两种"左右滑动"刻意做成不同材质，避免混淆：卡片**没有轨道**（拖动时浮出红/绿角标 + 顶部那行提示，
  而且是"定级"），滑片**有轨道**、药丸里直接写着"上一个 / 下一个"（是"翻词"）

## 2. 卡片下方新增「滑片」（翻词）

```
◀  ╭────────╮  ▶      往左拖 = 上一个词（= 撤销上一次作答那条路）
   ╰  翻词   ╯        往右拖 = 下一个词（跳过：不写库、记未标）
```

| 项 | 定案 |
|---|---|
| 位置 | 卡片正下方、卡片**外面**（卡片飞出时它不动），宽 = 卡片宽，高 44px |
| 跟手 | 1:1；越界用现成的 `rubberbandBeyond`（到边变硬） |
| 松手 | `project(v, 0.998)` 投射落点：≥ 半程 60% 或实拖 ≥ 全程 80% 判"翻"，否则回中 |
| 动画 | 翻 → `SPRING_FLY`（阻尼 .85）；回中 → `SPRING_BACK`（阻尼 .9）+ **速度接管**；飞行中可抓住；只动 transform；减弱动效直接跳 |
| 往右 | 今天「下一个」的行为：没答过才算跳过（`skipped++`、`done='skip'`）；答过的只是往前走，不重复计数 |
| 往左 | 上一题**答过**（栈顶快照正是它）→ 走已有 `goBack()`（数据级撤销）；只是**跳过** → 纯回退一格，并把那次跳过计数收回 |
| 端点 | 第一题左端禁用；最后一题右端 = 进小结；进小结 / 空队列整条收起 |
| 无障碍 | 轨道里放两个**真 `<button>`**（可点、可 Tab、`aria-label`），药丸 `aria-hidden` —— 不造假 slider 骗读屏 |
| 键盘 | 新增 **← / →** = 上一个 / 下一个（删了「下一个」按钮，跳过不能只剩拖动一条路） |
| 显示 | 两种模式都显示；**默写模式输入框一聚焦（键盘弹起）就先隐藏**，答完（焦点移到「下一题」）自己回来 |

实现细节：动作**不等动画**——松手即刻翻词，药丸同时飞向那一端再回中（否则要等 0.4 秒弹簧到位）。

## 3. 默写模式：答完揭晓「全部释义 + 搭配」

卡片内容顺序改成一套 DOM 服务两种模式：

```
词 → 音标·词性 → [输入框 + 检查] → 反馈 → ★揭晓块 → 下一题 → 生疏 | 熟记
```

- 过一遍模式：输入框 / 检查 / 反馈都藏起来 → 揭晓块自然落在音标下面（和原来那个位置一样）
- 默写模式：揭晓块在**反馈下面**，答完才淡入
- 揭晓内容：**全部**释义一行一条；**全部**搭配一行一条（按 换行 / `;` / `；` 拆条，没有就不渲染）；
  中→英方向最上面补一行**词头 + 音标**（那个方向题目只给中文，答完必须让人看到英文词）
- 揭晓时机：答对 / 答错 / 点「算我对」/ 英译中的"差不多对"都摊开；**中译英的"差一点点，再试一次"不摊开**
- 答错反馈因此简化成 `不对 ✗　·　已加入生疏词库`（原来那句"正确答案：…"跟揭晓块重复）

## 4. 顺手修掉的两个坑（不在原始要求里，但会误导判断）

1. **`tool/shot.html` 的主题是假的**：它靠写死一套 token 覆盖应用来钉深浅色，而应用早就改成
   `@media (prefers-color-scheme: dark)` —— 于是所有截图里的颜色都是错的（浅色被钉成白底白卡）。
   改成：浅色就把 dark 媒体块 `mediaText='not all'` 关掉（无头浏览器默认偏好深色），
   深色就把 dark 媒体块**拆开**塞进去（不另抄一份，永不漂移）。`shots/` 全部按真实调色板重出。
2. **练习页顶栏在 390px 下被挤成两行**（"第 1/10""选词"各自折行）：`.prac-top` 允许整块换行，
   让 `英→中 / 中→英 / 混合` 掉到第二行右对齐，并给进度与「选词」加 `nowrap`。

## 5. 明确不做
