# 首页瘦身 + 悬浮胶囊导航 + 删除词库（v18）实施方案

> **实施结果（2026-09-26，v18 已上线）**：方案基本照做，只有两处按用户当场拍板改了 ——
> **D1 改成"完全不留"**（首页连"今天"那一行都没有了），**D4 改成"只删库不删词"**（不删级联词条，
> 另外新增一个钉在顶部的**总词库**装所有导入过的词）。落地时 Task 3 的名字也简化成
> `deleteLibCascade`（只动 libs + links）；UI 侧多了 `ui-nav` 与 `ui-lib-delete` 两个测试文件，
> `verify_all` 从 17 步变成 19 步。下面正文保留当初的规划原文，便于对照"计划 vs 实际"。


> **给执行者**：这份方案是按任务（Task）拆的，每个 Task 自己带测试循环、能独立验收、独立提交。
> 建议用 `subagent-driven-development`（每个 Task 派一个干净的子代理 + 两阶段审查）或
> `executing-plans`（本会话内按 Task 批次执行，中间设检查点）来落地。

**目标（一句话）**：首页只留"今天一行 + 自动收集 + 词库列表"，把导入/设置搬进底部悬浮胶囊，并给词库补上"删除"。

**架构**：不动数据层结构（仍是 words / libs / links / prog / meta 五张表），只在 `store.js` 加两个纯函数
（`libOwnedWordIds` 算"只属于这个库的词"、级联软删除 + 撤销），界面层做减法：`ui-home.js` 去掉大卡片与页脚按钮，
`index.html` 的 `#tabbar` 改成三项悬浮胶囊，`app.js` 每次切界面维护 `aria-current`。

**技术栈**：原生 ES 模块、零依赖、零 CDN、无构建；IndexedDB；CSS 令牌体系；无头 Edge 跑浏览器内测试。

**规格**：`SPEC.md`（本方案要同时改 §3 删除语义、§7 界面结构、§10 验收标准）

## 全局约束（每个 Task 都适用，值照抄）

## 需要你点头的 5 个决定（每条都给了推荐）

| # | 决定 | 推荐 | 备选 |
|---|---|---|---|
| D1 | 综合练习（不分库的混合队列）入口放哪 | **首页第一行 `今天 · N 待复习 · M 新词 ›`**（一行，不是卡片，点进 `#/practice`） | 完全不留：只能点某个库或生疏词进练习（会丢掉"今天该练什么"这个唯一答案） |
| D2 | 「自动收集」（生疏词 / 熟记词）还留吗 | **留**，作为词库列表上方的一张卡 | 删掉 → 生疏词专项练习失去入口，不建议 |
| D3 | 新建词库入口 | **词库列表末尾一行虚线「＋ 新建词库」**（仍在词库里，符合"主页只有词库"） | 放进设置页（多两次点击） |
| D4 | 删库的删除范围 | **级联软删除：这个词库 + 它的关联 + 只属于它的词条**；与其他库共享的词只解除关联；`prog` 不动；给 5 秒「撤销」 | 只删词库、词条全留（会攒下一堆没人认领的孤立词） |
| D5 | 删除入口 | **每行右侧 `⋯` → 行内菜单（看词条 / 重命名 / 删除词库）** | 左滑露出「删除」（更快，但新手势、易误触、桌面不可用） |

> `⋯` 这个选择跟上一张 Apple Books 截图一致：Continue 卡片右上角就是一个 `⋯`，次要操作收进去，行本身只留主要内容。

```js
/** 只属于这个库的词 id：删库时会被一起删掉的那些（与别的库共享的不能删） */
export function libOwnedWordIds(data, libId) {
  const mine = libWordIds(data, libId);
  const shared = new Set();
  for (const l of data.links) {
    if (l.libId !== libId) shared.add(l.wordId);
  }
  return mine.filter((id) => !shared.has(id));
}
```

```js
/** 删除一个词库：软删除 它的关联 + 只属于它的词条 + 它自己。返回一个"撤销快照" */
export async function deleteLibCascade(data, libId, now = Date.now()) {
  const wordIds = libOwnedWordIds(data, libId);
  const linkIds = data.links.filter((l) => l.libId === libId).map((l) => l.id);
  for (const id of linkIds) await softDelete('links', id, now);
  for (const id of wordIds) await softDelete('words', id, now);
  await softDelete('libs', libId, now);
  return { libId, wordIds, linkIds, at: now };
}

/** 撤销上面那次删除（把 deleted 标记清掉；不动 updatedAt 的语义，只刷新它） */
export async function undoDeleteLibCascade(snap) {
  for (const [store, ids] of [['links', snap.linkIds], ['words', snap.wordIds]]) {
    for (const id of ids) {
      const row = await get(store, id);
      if (row) await put(store, { ...row, deleted: false, updatedAt: Date.now() });
    }
  }
  const lib = await get('libs', snap.libId);
  if (lib) await put('libs', { ...lib, deleted: false, updatedAt: Date.now() });
}
```
